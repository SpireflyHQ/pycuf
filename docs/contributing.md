# Contributing

Contributions are very welcome, especially reports of files from software that pycuf does not
handle well yet: use the
[file compatibility report](https://github.com/SpireflyHQ/pycuf/issues/new?template=file_compatibility.yml).

- [CONTRIBUTING.md](https://github.com/SpireflyHQ/pycuf/blob/main/CONTRIBUTING.md): development
  setup, everyday commands, adding finding codes and policy options, pull requests and releases.
- [ARCHITECTURE.md](https://github.com/SpireflyHQ/pycuf/blob/main/ARCHITECTURE.md): a map of the
  code and the invariants it keeps.
- [Anonymising a sample](how-to/anonymise-a-sample.md): how to share a file's quirk without sharing
  the file.

!!! danger "Never share real CUF files"
    Estimates contain client names and addresses and commercially sensitive prices. Never attach
    one to an issue or pull request, and never paste one into an AI service. Share the exporting
    software, the finding codes and a small hand-made or anonymised snippet instead.
