# Getting help

- **Documentation:** <https://spireflyhq.github.io/pycuf/>. The pages on
  [reading](https://spireflyhq.github.io/pycuf/guide/reading/),
  [calculating](https://spireflyhq.github.io/pycuf/guide/calculation/) and the
  [finding codes](https://spireflyhq.github.io/pycuf/reference/codes/) answer most questions.
- **Bugs, file-compatibility problems and feature requests:** search the
  [issues](https://github.com/SpireflyHQ/pycuf/issues) first, then open one with the matching form.
- **Security problems:** report them privately as described in [SECURITY.md](SECURITY.md), never
  in a public issue.

When you ask for help, include the pycuf and Python versions, the output of `pycuf info FILE`
(with names removed), the software that exported the file, and the finding codes. **Never attach
a real CUF file**: it contains client data and commercially sensitive prices. A small hand-made
snippet that shows the problem is enough;
the [anonymising guide](https://spireflyhq.github.io/pycuf/how-to/anonymise-a-sample/) explains
how to make one.

pycuf is maintained by one person in their spare time. It is not affiliated with Ketenstandaard Bouw en Techniek or
any software vendor; questions about how a particular package exports or imports CUF-XML belong
with that vendor.
