# Sample files

Synthetic CUF-XML files for trying pycuf without an estimate of your own. Every project, price
and name in them is made up.

| File | What it shows |
|---|---|
| `begroting.xml` | a tidy CUF-XML 4.003 file (UTF-8): 9 bundles, 12 estimate lines with resource and quantity take-off lines; stated totals agree with the lines |
| `begroting-ibis.xml` | the same estimate written the way Ibis writes it: Windows-1252, `xmlns:Ibis`, an empty `BTW` on every line, text lines, and labour totals that are deliberately €100 too high |

Download them with

```console
curl -L -O https://raw.githubusercontent.com/SpireflyHQ/pycuf/main/examples/begroting.xml \
        -O https://raw.githubusercontent.com/SpireflyHQ/pycuf/main/examples/begroting-ibis.xml
```

and follow the [quickstart](https://github.com/SpireflyHQ/pycuf#-quickstart) or the
[getting-started tutorial](https://spireflyhq.github.io/pycuf/getting-started/).

The files are generated by `scripts/gen_examples.py` from `tests/cufgen.py`; do not edit them by
hand (CI checks that they are current).
